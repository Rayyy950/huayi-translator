# 隐私说明（PRIVACY）

版本 0.1.0 · 2026-11-06

## 1. 一句话

- **本地模式**：划选的文字只在本机 Chrome 内翻译，不发出网络翻译请求。
- **云端模式**：只把**当前选中的文本**发送到你配置的腾讯云 TokenHub 区域；不发送整页内容、浏览历史或分析数据。
- 本项目没有自建服务器、账号系统、分析 SDK 或远程脚本。

## 2. 处理的数据

| 数据                     | 何时                           | 去向                                                | 保存                                                                         |
| ------------------------ | ------------------------------ | --------------------------------------------------- | ---------------------------------------------------------------------------- |
| 选中的文字               | 每次划选（仅当启用且站点允许） | 本地引擎：留在本机；云端模式：发送到腾讯云 TokenHub | 会话缓存最多 30 分钟；不写历史                                               |
| 源/目标语言、引擎模式    | 每次请求                       | 扩展后台                                            | 设置（local）                                                                |
| API Key                  | 用户保存时                     | 扩展后台读取；只发送给 TokenHub                     | 默认仅 `storage.session`（浏览器重启即失效）；用户勾选后写入 `storage.local` |
| 请求耗时、错误码、字符数 | 每次请求                       | 扩展后台                                            | 用量统计（local）；诊断不含原文与 Key                                        |
| 网站访问权限、禁用站点   | 用户设置                       | Chrome 权限系统 / 设置                              | 扩展存储                                                                     |

## 3. 网络请求

1. **Chrome 内置翻译模型**：由 Chrome 自身下载与管理；扩展只调用本地 API，不发起翻译网络请求。模型下载行为属于 Chrome 的组件更新，不由本扩展控制。
2. **腾讯云 TokenHub**：`POST https://tokenhub.tencentmaas.com/v1/chat/completions` 或新加坡对应域名；HTTPS，Bearer API Key。请求体包含提示词与选中文本。腾讯云对这些数据的使用与保留受其服务条款与隐私政策约束；本报告未验证其保留策略。
3. 没有其他第三方请求。扩展不从 CDN 加载脚本，不使用远程代码或 `eval`。

## 4. 本地存储与访问边界

| 存储                     | 内容                                         | 访问级别           |
| ------------------------ | -------------------------------------------- | ------------------ |
| `chrome.storage.local`   | 设置、长期 Key（可选）、Key 元数据、当天用量 | `TRUSTED_CONTEXTS` |
| `chrome.storage.session` | 会话 Key（默认）、30 分钟翻译缓存            | `TRUSTED_CONTEXTS` |
| 内存                     | 最近的 Translator 实例、进行中的请求、去重表 | 仅 Service Worker  |

- 网页脚本和 Content Script 不能读取上述存储；Content Script 只通过消息获取脱敏设置（不含 Key）。
- 不使用 `storage.sync` 保存 Key、原文或译文。
- 不在 URL、DOM、控制台日志或导出中放置 Key。
- 扩展存储不是操作系统保险箱；能访问你本机 Chrome 用户目录的人可能读取它。首版接受“自用 BYOK”模式，并提供删除 Key 入口。

## 5. 缓存与历史

- 译文只进入 `chrome.storage.session`，容量 200 条 / 2MB / TTL 30 分钟，LRU 淘汰。
- 正常关闭浏览器后缓存清空（实测）。
- “清理缓存”立即清除内存与会话缓存。
- 不做翻译历史、生词本、跨设备同步。

## 6. 权限

| 权限                             | 用途                          | 不用于                              |
| -------------------------------- | ----------------------------- | ----------------------------------- |
| `storage`                        | 设置、凭据、用量、会话缓存    | —                                   |
| `scripting`                      | 在已授权网站注册/注入划选脚本 | 不在未授权站点注入                  |
| 可选 `http://*/*`、`https://*/*` | 用户主动授权的网页访问        | 不把网页访问当作任意转发 URL 的授权 |
| TokenHub 域名（https 子集）      | 云端请求                      | 只由 Provider 固定端点使用          |

不申请 `cookies`、`history`、`webRequest`、`debugger`、`activeTab`、无限存储或 offscreen。

Chrome 的权限模型下，“授权所有网站”也会覆盖 https 域名权限，因此网页访问授权与云端域名授权存在实际重叠；本扩展不宣称二者完全隔离。

## 7. 用户控制

- 全局关闭划译。
- 按站点禁用（弹窗或设置页）。
- 选择“本地仅用”，永不发送云端。
- 删除本机 API Key。
- 清理缓存。
- 撤销网站访问权限（Chrome 扩展详情页或设置页）。
- 移除扩展会删除其 `storage.local` 与 `storage.session`。

## 8. 不做的事

- 不上传分析事件或崩溃报告。
- 不记录完整原文/译文到日志。
- 不收集鼠标轨迹、浏览历史、页面正文。
- 不读取密码框或可编辑区域内容。
- 不把翻译文本当作指令执行；只按纯文本渲染。
- 不在首版上架商店或提供共享生产密钥（用户自带 Key）。
