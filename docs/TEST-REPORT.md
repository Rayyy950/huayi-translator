通过的 20 个场景：

1. 划选显示译文、引擎、缓存命中
2. 慢请求先选、快请求后选 → 只显示后选
3. 两个标签同时翻译互不串扰

5. 复制到剪贴板

7. 超长选区提示而不截断
8. HTML 字样的原文/译文按文本渲染（`window.__xss` 未执行）
9. 云端未配置 Key → 明确配置错误 + “打开设置”
10. 本地不可用 + 已授权回退 → 一次云端回退并标注“回退”
11. 本地仅用 + 本地不可用 → 不调用云端
12. 鉴权失败不可重试；网络失败可重试
13. 请求进行中修改设置 → 过期结果被取消并提示“设置已更改”
14. 禁用站点 → 不读取选区、不显示浮层
15. 360×500 窄视口 → 浮层保持在视口内
16. 弹窗渲染与全局开关
17. Service Worker 被终止后，设置与翻译恢复
18. 多段选择保留段落边界
19. 在浮层内部划选不触发新翻译
20. 无划选时页面加载后不出现浮层（1.5 秒观察）

## 4. 性能

### 4.1 测量方法

- 真实 Chrome 156，`dist-test`，本地模型已准备，fixture 页面（localhost）。
- 计时从 `pointerup` 事件派发到浮层 `.translation` 可见，包含默认 250ms 防抖与 CDP 驱动开销。
- 每个场景 20 次；p95 使用 nearest-rank（`ceil(0.95×n)`）。
- 这是单机、单网络的短时测量，不等于 PRD 要求的“每个语言对、每个网络 30 次”完整报告。

### 4.2 结果

| 指标                                        | PRD 目标               | 实测                                                     | 样本 |
| ------------------------------------------- | ---------------------- | -------------------------------------------------------- | ---- |
| pointerup → 浮层可见（本地，含 250ms 防抖） | p95 ≤ 350ms            | p50 277.4ms / p95 281.5ms / max 352.5ms                  | 20   |
| 缓存命中 → 展示（不含防抖）                 | p95 ≤ 100ms            | 含防抖 p50 259.3ms / p95 263ms；扣除 250ms 防抖约 9–13ms | 20   |
| 本地热启动短句翻译（引擎层）                | p50 ≤ 1s，p95 ≤ 2s     | p50 6ms / p95 11ms（30 条 20–150 码点）                  | 30   |
| — 英文短句                                  | —                      | p50 6ms / p95 9ms                                        | 19   |
| — 日文短句                                  | —                      | p50 8ms / p95 13ms                                       | 11   |
| 首次模型准备                                | 单独记录，不混入热启动 | en→zh 约 8.5s；ja→zh 约 4.6s（单次，本机网络）           | 各 1 |
| 云端短句                                    | p50 ≤ 2s，p95 ≤ 4s     | **未验证（无凭据）**                                     | 0    |
| 普通网页短句成功率                          | ≥ 98%                  | fixture 20/20；真实网页 3/3；不代表实际网页总体          | 23   |
| 无划选时无请求                              | 必须                   | 页面加载 1.5s 无浮层；未做网络抓包统计                   | —    |

首次计时样本 352.5ms（首次创建 Translator 实例），高于其余样本；热启动 p95 为 281.5ms。

### 4.3 结论

- 本地路径在本次环境下达到 pointerup→可见、缓存处理、热启动短句目标。
- 真实网页的 280–380ms 与 fixture 一致（含防抖与页面复杂度影响）。
- 云端性能没有数据，不能宣称达标。

## 7. 安全与隐私检查

- 生产包 `dist/` 中 `grep 测试译文 / fakeTranslate` 无结果；测试 Provider 只在 `dist-test/`。
- 生产包无远程脚本、无 `eval`、无 CDN 依赖；所有运行时代码随扩展打包。
- `chrome.storage.local` 与 `session` 设为 `TRUSTED_CONTEXTS`；Content Script 不直接访问存储。
- 消息由 Zod 校验；设置/凭据/测试/缓存/权限类消息仅接受 `chrome-extension://<id>/` 发送方；翻译/取消仅接受有 tab 的 http(s) 发送方。
- 翻译文本按纯文本渲染；HTML 字样 e2e 验证不执行。
- 诊断只含错误类型/HTTP 状态，不含 Key 或原文。
- 打包脚本检查 `dist/` 不含 `probe`、`tests`、`src`、`node_modules`。
