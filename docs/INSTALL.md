# 安装与使用（INSTALL）

本文说明如何在自用环境安装、配置和验证「划译」0.1.0。首版未上架 Chrome 商店，也未购买任何云服务。

## 1. 环境要求

| 项目              | 要求                                                          | 本次验证环境             |
| ----------------- | ------------------------------------------------------------- | ------------------------ |
| 系统              | macOS / Windows / Linux 桌面版                                | macOS 26.2 (25C56)       |
| 浏览器            | 桌面版 Google Chrome 138 或更高                               | Chrome 156.0.8078.80     |
| Node.js（仅构建） | 20.19+ 或 22.12+                                              | Node 22.22.2，npm 10.9.7 |
| 网络              | 本地模型需要访问 Chrome 组件服务；云端需要访问腾讯云 TokenHub | 本机网络实测             |

Chrome 内置翻译只在桌面版提供；移动版、Chromium 分支和部分企业策略环境可能没有 `Translator` API。扩展会把这种情况显示为“本地不可用”，不会假装可用。

## 2. 构建

```bash
npm ci
npm run build
```

产物在 `dist/`。也可以直接使用交付的 `release/huayi-v0.1.0.zip`（解压后加载）。

## 3. 加载扩展

1. 打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择 `dist/`（或解压后的目录）。
4. 首次安装会自动打开设置页；之后可从工具栏图标 → “打开设置”进入。

## 4. 首次配置

### 4.1 授权网站访问

划译只在已授权的普通 HTTP/HTTPS 页面运行。

- 设置页 → “网站访问” → **授权所有 HTTP/HTTPS 网站**；或
- 输入一个域名（例如 `example.com`）→ **授权指定网站**。

Chrome 会弹出原生授权确认。授权后会自动向已打开的匹配页面注入一次脚本；其他页面在刷新后生效。Chrome 内部页面（`chrome://`）、扩展商店、内置 PDF 阅读器不支持。

撤销授权：在设置页“网站访问”的列表里点“撤销”，或在 Chrome 扩展详情页修改网站访问权限。撤销后扩展不再为该站点翻译；已在页面中的旧脚本也无法通过后台校验。

### 4.2 本地翻译（推荐，免费、离线）

1. 设置页 → “本地翻译”。
2. 依次点击：
   - **准备英→中模型**
   - **准备日→中模型**
   - **准备语言检测**（使用“自动检测”源语言时需要）
3. 每个按钮需要单独点击：Chrome 要求模型下载由一次用户手势触发。下载期间会显示真实进度；首次下载可能较慢，请保持设置页打开直到完成。
4. 状态变为“已准备”即可。模型保存在当前 Chrome 配置中，重启浏览器后仍在；翻译本身在扩展后台运行，不需要一直开着设置页。

本地模式不会产生网络翻译请求。模型下载使用 Chrome 自身的组件更新服务。

### 4.3 云端翻译（腾讯云 TokenHub）

首版云端 Provider 是腾讯云 **TokenHub** 的 `hy-mt2-plus`，不是已退市的旧版机器翻译 `TextTranslate`（原因见 [FEASIBILITY.md](FEASIBILITY.md)）。

1. 注册/登录腾讯云，进入 TokenHub 控制台：<https://console.cloud.tencent.com/tokenhub/apikey>。
2. 在控制台**开通 `hy-mt2-plus` 模型**（未开通时接口返回 402）。
3. 创建 API Key；确认 Key 所属区域（广州或新加坡）。Key 与区域绑定，不能跨区域使用。
4. 建议在腾讯云账户中检查后付费开关、预算和额度提醒。**本项目不会代购或保证免费额度。**
5. 回到设置页 → “云端翻译”：
   - 选择与 Key 相同的区域；
   - 粘贴 API Key；
   - 默认勾选“仅本次会话保存”；如需重启后仍可用，勾选“在本机长期保存”；
   - 点击“保存 Key”，在 Chrome 弹出的域名授权中允许 `tokenhub.tencentmaas.com` / `.cn`（或新加坡对应域名）；
   - 点击“测试连接”。测试会发送一条短英文示例，**可能消耗额度**。
6. 测试成功后才说明云端可用。失败时按错误提示处理：
   - `AUTH_FAILED`：Key 错误或区域不匹配；
   - `QUOTA_EXCEEDED`：额度不足或模型未开通；
   - `PERMISSION_DENIED`：未授予 TokenHub 域名访问权限；
   - `NETWORK_ERROR`：网络/代理无法访问端点。

API Key 只保存在本机扩展可信存储中；页面脚本和内容脚本无法读取。扩展不会把 Key 写入日志、URL 或导出文件。扩展存储不是系统级保险箱，请自行保护本机账户。

### 4.4 选择引擎模式

设置页 → “翻译引擎”：

- **本地优先**（默认）：本地可用时用本地；不可用/失败时，只有在你开启“允许本地失败时回退到云端”后才发送到云端一次。
- **固定云端**：始终使用 TokenHub。
- **本地仅用**：绝不向云端发送文本；本地模型未准备时不翻译。

“本地失败时回退到云端”默认关闭；开启时页面会说明数据流向。切换为“本地仅用”会自动关闭回退。

## 5. 使用

1. 在已授权网页中用鼠标划选英文或日文（单词、句子、多段均可）。
2. 松开鼠标约 250ms 后，选区附近出现浮层。
3. 浮层显示语言方向、实际引擎（本地/云端/回退）、译文。
4. 底部：**复制**、**重试**；顶部：**固定**、**关闭**。
5. 点击浮层外或按 `Esc` 关闭（固定状态仍需 `Esc` 或关闭按钮）。
6. 固定后滚动页面仍显示；新划选会替换内容并保留固定状态。
7. 工具栏图标弹窗：全局开关、当前网站开关、引擎模式/本地/云端状态、打开设置。

其它行为：

- 相同文本重复划选会命中 30 分钟会话缓存（显示“缓存”）。
- 选区超过 5000 字符会提示缩小选区，不会截断。
- 密码框、输入框、textarea、contenteditable 内不触发。
- 点击/划选浮层内部不会触发新翻译；浮层文本可正常选择复制。
- 中文等非英日文本：自动检测不可靠时会提示手动指定源语言；已是简体中文时提示无需翻译。

## 6. 已知限制

- 目标语言首版固定为简体中文（只验证了 en/ja → zh-Hans）。
- 本地引擎依赖 Chrome 内置 AI。若 Chrome 不提供，设置页显示“不支持”，请使用云端。
- 本地翻译在 Service Worker 中使用 Translator API，这是 Chrome 156 的未文档化行为；未来版本可能变化。不可用时会有明确提示。
- 云端真实翻译质量、延迟与额度需要用户自己的 TokenHub Key 验证；仓库内没有成功调用记录。
- 仅支持顶层 frame；跨域 iframe、PDF、Canvas、封闭 Shadow DOM 不在 P0 范围。
- 本地翻译串行；多个页面同时长文本翻译时，后到请求可能等待或超时。
- 云端两块以上的长文本极端情况下可能超过单次 12 秒总时限。
- 站点权限与云端域名权限存在 Chrome 层面的重叠，无法完全隔离。
- Chrome 扩展的网站访问授权弹窗是原生 UI，自动化测试无法代替人工点击；请按第 4.1 节手动完成。

## 7. 测试构建（仅开发/测试）

```bash
npm run build:test
```

生成 `dist-test/`，包含：

- 预先授予 `http://*/*`、`https://*/*`（便于自动化，不需要原生授权弹窗）；
- 仅测试可用的假 Provider（`useFakeProvider` 设置隐藏，生产构建中该模块被移除）。

按第 3 节加载 `dist-test/`，在设置页之外通过消息把 `engineMode` 设为 `cloud-only`、`useFakeProvider` 设为 `true` 即可使用假翻译。**不要把 `dist-test` 当作正式版本使用。**

## 8. 卸载与清理

- `chrome://extensions` → 划译 → 移除。
- 移除扩展会删除其 `storage.local`（设置、长期 Key、用量）与 `storage.session` 缓存。
- 已在设置页删除 Key 的用户，扩展存储中不再保留 Key。
- 删除后 Chrome 已下载的本地翻译模型属于 Chrome 自身组件，不随扩展删除。

## 9. 手动验收清单（另一个人复现）

- [ ] 加载 `dist/`，设置页自动打开。
- [ ] 授权一个测试网站；刷新页面。
- [ ] 准备英→中、日→中、语言检测（三次点击）。
- [ ] 划选英文句子 → 浮层出现简体中文，引擎显示“本地”。
- [ ] 划选日文段落 → 浮层出现译文。
- [ ] 重复划选 → 显示“缓存”。
- [ ] 固定后滚动 → 浮层仍在；Esc 关闭。
- [ ] 快速先选慢文本再选快文本 → 只显示后者。
- [ ] 打开第二个标签同时划选 → 互不串扰。
- [ ] 弹窗中关闭当前网站开关 → 该站点不再翻译（原生弹窗需人工操作）。
- [ ] 配置 TokenHub Key 并测试连接 → 显示真实成功/失败（需要用户自己的 Key 与额度）。
- [ ] 关闭云端回退、禁用本地模型 → 不产生云端请求。
- [ ] 清理缓存 → 再次划选重新请求。
